# Direction

Gene is the serious, structured operator. Fri will be the playful, slightly sarcastic
companion. Start with one visible bot and separate internal responsibilities. A later
Fri process can use distinct Discord credentials and connect to the same approved
server facts, requests, and release coordinator. It must not become a competing deployer.

The first milestone is a reliable invisible lab: native Red commands/music, meme
voting, and a complete reviewed feature-release cycle. Recover the old bot's exact
configuration from historical evidence rather than assuming old prefixes, cogs, or thresholds.

Next, improve workshop conversations: clarification threads, concise progress updates,
small proposed memories, issue grouping, and regression reports. Keep context explicit
and inspectable. Private Codex development automation is distinct from using subscription
authentication as a general hosted AI-chat service; general companion chat needs a
supported integration and its own product/auth design.

After successful lab use, promote the same tested artifacts into the friend server
through an explicit configuration change and review the bot's permissions. Enable
normal presence only when the owner asks. Keep the lab for future changes.

Later capabilities may include Spotify metadata support, a separate Fri operator,
and controlled infrastructure jobs such as Minecraft provisioning. Each capability
needs a concrete plan, dedicated credentials, resource limits, approval and rollback.
No Discord text becomes an unrestricted SSH or shell command.
